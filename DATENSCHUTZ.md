# Datenschutz beim DasDimo Launcher

Stand: 2. November 2026 · [English version below](#privacy-of-the-dasdimo-launcher)

Der DasDimo Launcher sammelt keine Daten und schickt nichts an DasDimo. Es gibt keine Anmeldung, kein Konto und keinen eigenen Server.

- **GitHub:** Spieleliste, Spiele, Bilder und Updates kommen von GitHub. GitHub sieht dabei deine IP-Adresse, wie jede Webseite, die du aufrufst. Dafür gelten die Datenschutz-Regeln von GitHub.
- **Auf deinem PC:** Einstellungen, Spielzeit und die Protokoll-Datei `launcher.log` bleiben auf deinem PC. Die Protokoll-Datei geht nur weiter, wenn du sie selbst jemandem schickst.
- **Das frühere Konto:** Das freiwillige DasDimo-Konto gab es in den Launchern 2.1.0 bis 2.2.1. Es ist abgeschaltet, Server und Konto-Daten sind gelöscht. Ab 2.3.0 löscht der Launcher auch den Anmelde-Schlüssel auf deinem PC.

Dieser Text gilt für den Launcher. Spiele und Mods können eigene Regeln haben.

# Privacy of the DasDimo Launcher

Last updated: 2 November 2026

The DasDimo Launcher collects no data and sends nothing to DasDimo. There is no sign-in, no account and no server of its own.

- **GitHub:** The game list, games, pictures and updates come from GitHub. GitHub sees your IP address while doing so, like any website you open. GitHub's own privacy rules apply.
- **On your PC:** Settings, play time and the log file `launcher.log` stay on your PC. The log file only goes further if you send it to someone yourself.
- **The former account:** The optional DasDimo account existed in launchers 2.1.0 to 2.2.1. It is switched off, the server and the account data are deleted. From 2.3.0 on, the launcher also deletes the sign-in key on your PC.

This text applies to the launcher. Games and mods can have their own rules.
